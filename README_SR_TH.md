# SR Paper Desk: แนวรับแนวต้าน + เทรน (แทน BPE/ICT)

เซิร์ฟเวอร์นี้ฟอร์เวิร์ดเทสต์กลยุทธ์ "แนวรับแนวต้านตามเทรน" ด้วยบัญชีจำลอง ไม่ส่งคำสั่งจริง ไม่ใช้คีย์โบรกเกอร์
ใช้ราคาจาก Yahoo (FEED=yahoo, NQ=F) จึงไม่ต้องมีคีย์ใดๆ บน Railway ยกเว้น API_KEY ของแดชบอร์ด

## กติกา (ตั้งก่อนทดสอบ ห้ามปรับตามผลเทรนไม่กี่ไม้)
- แนว 4 ระดับ: PDH/PDL (สูง/ต่ำของช่วงเทรดปกติ 09:30-16:00 นิวยอร์กของวันก่อน) และ ONH/ONL (สูง/ต่ำช่วงกลางคืน 18:00 -> 09:30)
- เข้าเมื่อราคาแตะแนวครั้งแรกในช่วง 09:30-12:00 นิวยอร์ก แล้วปิดแท่ง M5 กลับด้านที่ถูก (รับ: low แตะแล้วปิดเหนือแนว / ต้าน: กลับกัน)
- เฉพาะตามเทรน: เทรน = EMA20 เทียบ EMA50 ของแท่งชั่วโมงที่ปิดแล้ว (ซื้อเมื่อเทรนขึ้น ขายเมื่อเทรนลง) แนวที่แตะแล้วสวนเทรนถือว่าใช้ไปแล้ว ไม่เข้า
- เข้าตลาดที่ราคาปิดแท่งสัญญาณ, Stop = แนว -/+ 0.825 x ATR14, เป้า = 2R, ปิดทุกไม้ 16:00 นิวยอร์ก, ครั้งละไม้เดียว
- วันจันทร์และวันหลังวันหยุดไม่มีแนว (เหมือนแบ็กเทสต์: วันก่อนหน้าคือคืนวันอาทิตย์ที่ไม่มีช่วงเทรดปกติ) ถ้าอยากใช้วันศุกร์ ตั้ง SR_CONFIG={"mondays":true} (ยังไม่เคยทดสอบ)
- ไม่ใช้ footprint ในเวอร์ชันนี้ (ผลทดสอบ 2025 ไม่เห็นว่าเพิ่ม edge เหนือตัวกรองเทรน)

ผลแบ็กเทสต์ (2025-04..06, ยังไม่ใช่การพิสูจน์): ตามเทรน 30 เทรด เฉลี่ย +0.17R หลังต้นทุน ช่วงข้อมูลใหม่ที่ไม่เคยเห็น -0.17R
ตัวเลขใกล้ศูนย์ ใช้ฟอร์เวิร์ดเทสต์นี้เพื่อดูว่ามี edge จริงหรือไม่ก่อนจ่ายค่าสอบ

## ตรวจว่าทำงาน
- เปิด https://<แอป>.up.railway.app/health ควรเห็น "strategy":"sr" และ signalEngine เป็นจำนวนแท่ง (เริ่ม ~0 แล้วขึ้นหลังดึงราคา warm-up 30 วัน)
- หน้าแดชบอร์ดมีกล่อง "แนววันนี้" แสดง PDH/PDL/ONH/ONL, เทรนชั่วโมง และสถานะสอบ
- GET /api/sr (ใส่ header x-api-key) ดูแนว เทรน และจำนวนสัญญาณ
- บัญชีจำลองเปิดและปิดไม้เอง (ไม่ต้องใช้ ESP32) ทุกสัญญาณถูกบันทึกในตารางสัญญาณพร้อมเหตุผล

## หมายเหตุ
- ฟีด Yahoo ไม่เป็นทางการและบางครั้งขาด ถ้าแท่งหาย เซิร์ฟเวอร์จะแจ้งเตือนในแดชบอร์ด
- ราคา Yahoo เป็นสัญญา NQ=F (ขนาดเต็ม) ใช้ราคาเท่ากับ MNQ จึงใช้จำลองได้ แต่ spread/ลื่นไถลจริงต่างกัน ตั้ง SPREAD_US100 ถ้าต้องการ (ค่าเริ่มต้น 0.25 จุด)
- ESP32 ไม่จำเป็นสำหรับโหมดนี้ (เซิร์ฟเวอร์เทรนเอง) สัญญาณถูกทำเครื่องหมาย taken แล้ว (ยังไม่ได้ทดสอบกับเฟิร์มแวร์ ESP32 จริง ถ้าใช้ ESP32 อยู่ ให้ปิดการวางออเดอร์ของมันเพื่อกันซ้ำ)
